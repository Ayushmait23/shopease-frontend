# ShopEase — Responsive E-commerce Frontend

A frontend-only demo storefront built with React, JavaScript, CSS, and Vite. This is an independent practice/portfolio project and is not connected to Aarvik Industries or a payment backend.

## Features
- Responsive storefront layout
- Product category filters and search
- Product cards with prices and ratings
- Wishlist toggle
- Shopping cart with quantity controls and subtotal
- Newsletter form interaction
- Mobile-friendly layout
- Demo checkout notice (no real payment processing)

## Run locally
1. Install Node.js (LTS).
2. In this folder, run:
   ```bash
   npm install
   npm run dev
   ```
3. Open the local URL shown by Vite.

## Build
```bash
npm run build
```

## Technologies
React, JavaScript (ES6+), HTML5, CSS3, Vite, Lucide React.
